# Contributing

Run `python -m unittest discover -s tests -v` and `python scripts/demo.py` before a PR.
Install `.[pdf]` to include PDF tests. Use synthetic documents for issues and tests.

Bug reports should include Python/OS versions, exact commands, expected and actual
output, and a minimal non-sensitive fixture. For MCP issues, include the client and
its version plus a sanitized configuration. Do not attach real receipts or documents.

Keep changes focused on observable document access. Claims about comprehension,
client delivery, visual inspection, or tamper resistance need separate evidence.
